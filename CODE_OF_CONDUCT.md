# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work, and
no harassment of anyone, in any form, in any project space (issues, pull
requests, reviews, discussions).

Report unacceptable behaviour privately to the maintainers through GitHub's
private vulnerability reporting (**Security → Report a vulnerability**), and say
in the title that it is a conduct report. Reports are kept confidential. The
maintainers decide on and apply the enforcement steps the Covenant describes.
